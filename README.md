# Bithou's Hub - 个人极客专属导航面板 🚀

为 **Bithou** 定制的轻量级、高颜值、纯静态数字看板与聚合导航站。

## 🌟 核心特性
- **极简极客美学**：深空暗黑主题，动态极光渐变光晕，Glassmorphism 毛玻璃微质感。
- **动态时钟与问候**：根据当前时间自动切换问候语，毫秒级数字时钟显示。
- **全网聚合搜索**：支持 Google、百度、GitHub、豆瓣电影、MoonTV 站内一键快捷直达搜索（按 `/` 键快速聚焦）。
- **全生态服务矩阵卡片**：
  - 🎬 **流媒体**：MoonTV、LibreTV、YouTube、Bilibili
  - 🖥️ **运维监控**：CF 探针、Uptime 监控、WebSSH、NodeWarden、宝塔面板
  - 🛠️ **极客工具**：今日热搜、Telegraph 图床、订阅追踪、AI 提示词优化、IP 检测
  - 🔐 **核心设施**：Bitwarden 密码库、Cloudflare 控制台、GitHub
- **支持实时编辑**：自带添加新网站弹窗，支持导出/导入 JSON 配置备份。
- **纯静态免运维**：单个静态文件驱动，100% 免费托管在 Cloudflare Pages，全球 CDN 毫秒级直达。
